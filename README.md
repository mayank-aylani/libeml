# EML — Earl Machine Learning Library  Build machine learning applications powered by EML in C/C++.  EML (Earl Machine Learning Library) is a modular machine learning library being developed from scratch in C/C++. The goal is to provide reusable building blocks for numerical computing, data processing, optimization, classical machine learning, and eventually neural-network workloads without relying on high-level machine learning frameworks.  The project brings the different components of my machine learning work together into a single reusable library.  ---  ## Overview  EML is designed around a modular architecture where numerical and machine-learning components can be developed, tested, and reused independently.  The library aims to provide components for:  - N-dimensional arrays and views - Vector and matrix operations - Numerical computing - Data preprocessing - Optimization algorithms - Regression - Classification - Neural networks - Dataset management - Model serialization - Model evaluation  The long-term goal is to make it possible to build ML applications directly in C/C++ using EML as the underlying machine-learning library.  ---
