## About

EML (Earl Machine Learning Library) is a modular machine learning library being developed from scratch in C/C++.

The goal is to provide reusable building blocks for numerical computing, data processing, optimization, classical machine learning, and neural-network workloads without relying on high-level machine learning frameworks.

The project brings together different components of my machine learning work into a single reusable library, making it possible to build ML applications directly in C/C++ using EML as the underlying library.

---

## Features

- N-dimensional arrays and views
- Vector and matrix operations
- Numerical computing
- Data preprocessing
- Optimization algorithms
- Regression
- Classification
- Neural networks
- Dataset management
- Model serialization
- Model evaluation
